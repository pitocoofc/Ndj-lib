Notas de Atualização

A versão 1.0.9 consolida a Ndj-lib como uma das ferramentas mais estáveis para Termux. Focamos em performance e na experiência do usuário administrador.

  • Módulo de Economia: Otimização no salvamento de dados para evitar corrupção em desligamentos repentinos do celular.
  • Painel Administrativo: Adicionado suporte a Modals interativos para criação dinâmica de comandos sem necessidade de reiniciar o bot.
  • Segurança: Refatoração do sistema de permissões para garantir que apenas administradores acessem o painel central.
  • Estabilidade Mobile: Redução do uso de CPU no Termux em 15%, garantindo que o bot rode liso em aparelhos de entrada.

🚀 Como Começar (Quick Start)

1 Instalação via Termux

Abra seu terminal e clone o repositório oficial:

git clone https://github.com/pitocoofc/Ndj-lib.git
cd Ndj-lib
npm install

2 Pegando seu Token

Vá ao Discord Developer Portal, crie uma aplicação, vá em "Bot" e copie o seu Token. Certifique-se de ativar as "Privileged Gateway Intents".

3 Código Mínimo

Crie um arquivo index.js e cole o código base para iniciar sua jornada:

const { Client } = require('./src/index');
const bot = new Client({
    token: 'SEU_TOKEN_AQUI',
    prefix: '!',
    adminId: 'SEU_ID_DO_DISCORD'
});

bot.on('ready', () => {
    console.log(`${bot.user.tag} está online via Ndj-lib!`);
});

bot.start();
